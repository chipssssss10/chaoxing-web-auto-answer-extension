# 设置参数详解

打开扩展 → **接口与自动化设置**。第一次只需填写 API 地址、模型名称和 API 密钥；其余参数可以先用默认值。修改设置后，请停止并重新开始已有任务，使整次任务使用一致的设置。

## 一、AI 接口

| 参数 | 默认值 | 含义与填写方法 |
| --- | --- | --- |
| API 完整地址 | `https://api.openai.com/v1/chat/completions` | 使用哪个服务商的 Chat Completions 接口。可填完整地址，或服务商提供的基地址，例如以 `/v1` 结尾的地址；程序会补上 `/chat/completions`。普通服务商主页、网页聊天地址不能代替 API 地址 |
| 模型名称 | 留空，需填写 | 填服务商提供的实际模型 ID。它不是随意起的显示名称。不同服务商、账号权限和模型可能支持不同参数 |
| API 密钥 | 留空，需填写 | 填自己的 API Key。只保存在此浏览器的扩展本地存储中，不同步云端；存储未加密，共享电脑使用后请清除 |
| 发送 JSON 模式参数 | 关闭 | 勾选后发送 `response_format: {"type":"json_object"}`，要求接口以 JSON 格式返回结果，方便程序读取选项、置信度和说明。接口需支持该参数；不支持时可能报错 |

公网 API 地址需要 HTTPS；本地演示可使用 `http://127.0.0.1` 或 `http://localhost`。地址不要包含账号、密码、查询参数或片段。

### JSON 模式是什么？

它约束的是回复格式，例如：

```json
{"answers":["A"],"confidence":0.95,"explanation":"简短依据"}
```

扩展读取 `answers` 来选择页面选项，读取 `confidence` 来决定是否提醒。多选题的 `answers` 可以包含多个字母。开启 JSON 模式不能保证答案正确，也不能保证字段内容符合要求，因此扩展仍会校验选项、题型和置信度。

即使没有勾选，扩展也会在提示词中要求 JSON 输出。[DeepSeek 官方 JSON 输出文档](https://api-docs.deepseek.com/guides/json_mode/)说明了该参数的用法；使用 DeepSeek 官方兼容接口时可以开启。

### 接口相关按钮

| 按钮 | 作用 |
| --- | --- |
| 保存设置并授权 API 域名 | 保存本页所有设置，并向浏览器申请访问所配置 API 域名的权限。保存不代表接口已测试成功 |
| 测试已保存的接口 | 使用已经保存的配置发送一道简单题，检查连接和答案解析；可能产生一次服务商费用。修改后先保存，再测试 |
| 清除已保存密钥 | 删除扩展本地保存的 API 密钥。正在运行的任务仍应另行点击停止 |
| 打开本地模拟页 | 打开 `http://127.0.0.1:8765/demo`。需要先启动项目自带的本地演示服务器，不是学习通实际答题页 |

## 二、自动化行为

| 参数 | 默认值 | 范围 / 单位 | 作用 |
| --- | --- | --- | --- |
| AI 低自评率提醒阈值 | `85` | 0–100，百分比 | AI 自评**低于**此值时提示约 3 秒并继续作答，结束后一起汇总；等于阈值不提示，填 0 可关闭提醒 |
| 每题完成后间隔 | `1200` | 300–10000 毫秒 | 当前题答案选中并确认后，等待多久再继续。1200 毫秒等于 1.2 秒 |
| 每次最多题数 | `100` | 1–500 题 | 限制一次任务最多处理的题数。达到上限后暂停，不继续翻题或自动提交；题数多时可事先调大 |
| 接口超时 | `25000` | 3000–25000 毫秒 | 一次 AI 请求最多等待多久。25000 毫秒等于 25 秒，超时会取消本次请求、显示实际等待秒数和处理建议，并暂停任务；不自动重试 |
| 选完后自动点击提交 | 关闭 | 开 / 关 | 开启后，在选完识别到的题目、没有可用下一题按钮时，尝试最终提交并确认明确的页面内提交对话框 |

### 低自评率示例

阈值设置为 `85` 时，AI 自评 80% 会提示，85% 和 95% 不会提示。请填 `85`，不是 `0.85`。扩展内部以 0–1 保存，但设置页面会显示和接受百分比。

低自评率只会提醒，不会因此暂停。非法答案、接口错误、超时和无法核验选中状态等情况仍会暂停。自评率是模型估计，不是经过验证的正确率。

任务结束后：

- 有低自评率题目：显示题干、AI 参考选项及自评率，方便复核。
- 没有：显示“没有 AI 自评率过低的题目”。

### 自动提交的使用方式

先用“只答一道”核对页面适配。开启自动提交时应从第一题开始；扩展只能核验本次识别到的题目，无法证明整份试卷没有遗漏。低自评率提醒不会阻止已开启的自动提交。

浏览器原生确认框需手动处理。没有可识别的成功提示时，扩展会要求检查结果。提交前停止可以取消后续等待和尚未执行的确认操作，不能撤销已生效的提交。

## 三、页面适配：自定义 CSS 选择器

**先全部留空即可。** 默认识别常见题块和单选 / 多选控件。只有识别不完整或找不到按钮时，才需要配置。

CSS 选择器是网页元素的定位规则。常见写法：`#nextQuestion` 表示 ID，`.question-item` 表示类名，`[data-correct='false']` 表示属性条件；它们不是题目的答案。

| 参数 | 查找范围 | 示例 | 应匹配什么 |
| --- | --- | --- | --- |
| 题块容器 | 整个答题区域文档 | `.TiMu`、`.questionLi`、`.question-item` | 一道完整题目的外层元素，内部应包含题干和全部选项；不要匹配整份试卷 |
| 题干 | 每个题块内部 | `.Zy_TItle`、`.mark_name`、`.question-title` | 题目文字，尽量包含单选、多选、判断等类型说明；不要把全部选项一起当作题干 |
| 每个选项的外层元素 | 每个题块内部 | `.Zy_ulTop > li`、`.options > li` | 一个元素对应一个选项，里面包含文字和可点击的 radio / checkbox 或可读取状态的自定义控件 |
| 下一题按钮 | 整个答题区域文档 | `#nextQuestion` | 唯一的下一题或下一页按钮，不要匹配答案卡中的多个题号 |
| 最终提交按钮 | 整个答题区域文档 | `#submitPaper` | 唯一的最终提交 / 交卷按钮，不是保存草稿按钮 |
| 错题批改标记 | 当前题块容器及其内部 | `.question-wrong`、`[data-correct='false']` | 错题容器或明确的错误批改标记。不要匹配题干中的“错误”文字或未选中选项的样式 |

默认按钮会按“下一题”“下一页”“提交试卷”“交卷”等可见文字查找。自定义按钮选择器如果匹配多个元素，程序会暂停并要求缩小范围。

扩展会优先读取原生 radio / checkbox 的选中状态。自定义选项需要能通过 `aria-checked`、`data-selected`、`selected / active / checked / check_answer / check_answer_dx` 等状态识别，否则会暂停，避免把“点击过”当成“已选中”。

改完选择器后，先扫描核对，再用“只答一道”验证。不同学习通版本可能需要进一步修改源码中的 `extension/dom.js`。

## 四、扩展弹窗中的按钮

| 按钮 / 区域 | 作用 |
| --- | --- |
| 扫描当前答题页面 | 读取当前已加载的题干、选项和题型，显示识别预览；不会调用 AI 或选择答案 |
| 答题区域 | 多个 iframe 中识别到题目时，选择要操作的区域 |
| 只答一道 | 回答当前区域中识别到的第一道待处理题，选中后停留；不自动翻页或提交 |
| 连续作答 | 在一次任务中连续回答、核验选中状态并翻题；最终是否提交取决于设置 |
| 停止任务 | 停止当前任务、取消等待并关闭网页右下角提示框；已选中的答案保持原状 |
| 扫描错题 | 只读扫描当前已加载的可见批改结果，报告错题、部分正确、未识别和标记冲突；不调用 AI、不改答案、不自动翻页 |
| AI 自评率汇总 | 查看本次低于提醒阈值的题目；任务结束后没有这类题目也会明确说明 |
| 错题扫描结果 | 查看上次扫描报告、扫描时间和依据。换页后请重新扫描，不代表整个课程或所有分页都已扫描 |

## 五、建议的首次配置

1. 填写自己的 API 地址、模型名称和密钥。
2. 官方接口支持时打开 JSON 模式；不确定时先保持关闭并测试。
3. 提醒阈值先用 `85`，间隔用 `1200`，超时用 `25000`。
4. 自动提交先保持关闭，所有 CSS 选择器留空。
5. 保存并授权 → 测试接口 → 扫描答题页面 → 只答一道。

完整安装流程和故障排查见 [部署与使用指南](DEPLOYMENT.md)。
