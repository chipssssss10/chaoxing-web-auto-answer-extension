# 部署与使用指南

本项目以浏览器扩展形式安装在自己的电脑上，无需部署服务器，也无需发布到 Edge 扩展商店。日常使用只需要 Edge / Chrome 和你自己的 AI API；Node.js 只用于可选的本地演示或开发测试。

## 一、从 GitHub 获取项目

1. 打开本项目的 GitHub 仓库。
2. 点击 **Code → Download ZIP** 下载源代码。
3. 解压到准备长期保留的目录，例如 `D:\学习通自动答题`。
4. 确认其中存在 `extension\manifest.json`。

浏览器加载扩展后仍会从原文件夹读取文件，请保留该文件夹。不要直接选择 ZIP 文件，也不要把外层项目目录当成扩展目录。

## 二、在 Microsoft Edge 中安装

1. 打开 Edge，在地址栏输入 `edge://extensions`，按回车。
2. 开启 **开发人员模式 / 开发者模式**。
3. 点击 **加载解压缩的扩展 / 加载已解压的扩展程序**。
4. 选择项目里的 **`extension` 文件夹**，例如 `D:\学习通自动答题\extension`。
5. 点击“选择文件夹”，确认列表中出现“学习通 AI 答题助手”。
6. 点击 Edge 右上角的扩展图标，将助手固定或显示在工具栏，方便打开。

这是微软支持的本地加载流程，具体名称可能随 Edge 语言和版本略有区别：[微软官方安装说明](https://learn.microsoft.com/en-us/microsoft-edge/extensions/getting-started/extension-sideloading)。

Chrome 的步骤相同，将管理页地址替换为 `chrome://extensions`。

## 三、填写 AI 接口

1. 点击扩展图标，选择 **接口与自动化设置**。
2. 填写 API 地址、模型名称和 API 密钥。
3. 点击 **保存设置并授权 API 域名**。
4. 如果浏览器请求访问该 API 域名，同意后才能连接对应接口。
5. 点击 **测试已保存的接口**。它会发送一道简单题，检查能否连接和解析答案，可能产生一次 API 调用费用。

### DeepSeek 配置示例

| 设置项 | 示例 |
| --- | --- |
| API 地址 | `https://api.deepseek.com/chat/completions` |
| 模型名称 | `deepseek-flash`，实际以自己账号可用的模型 ID 为准 |
| API 密钥 | 自己在 [DeepSeek 开放平台](https://platform.deepseek.com/) 创建的 API Key |
| 发送 JSON 模式参数 | 官方接口支持时可以勾选 |

DeepSeek 的官方 JSON 输出示例使用上述模型名和兼容接口格式，并支持 `response_format`：[DeepSeek JSON Output](https://api-docs.deepseek.com/guides/json_mode/)。模型及可用性可能变化，请以官方文档与自己的账号权限为准。

密钥直接填写在扩展设置中，不需要写进源代码、README 或 GitHub。网页登录的密码不等于 API 密钥；第三方中转服务也需要填写该服务自己的地址和模型 ID。

各项参数的含义、默认值和范围见 [设置参数详解](SETTINGS.md)。

## 四、首次使用

1. 在 Edge 打开学习通的实际答题页面，确认能看到题干和选项。
2. 安装或更新扩展后，刷新一次答题页面。
3. 点击扩展 → **扫描当前答题页面**。
4. 核对题干、选项、题型；如果显示多个答题区域，选择包含当前题目的区域。
5. 第一次先点击 **只答一道**，检查页面实际选中的选项是否与助手显示的 AI 参考选项一致。
6. 确认适配正确后，点击 **连续作答**。
7. 关闭扩展弹窗后任务仍会继续，页面右下角会显示进度；点击那里的 **停止** 会立即取消等待并收起提示框，也可以在扩展弹窗里点击 **停止任务**。

目前支持文本单选、多选和判断题。图片、音视频、画布题以及填空、简答题不在自动处理范围内。

## 五、低自评率提醒与汇总

在设置中将 **AI 低自评率提醒阈值** 填为百分比，例如 `85`：

- AI 自评低于 85% 时，右下角会短暂提示约 3 秒，并继续作答。
- 结束后汇总相关题干、AI 选项和自评率，可在页面提示框及扩展弹窗查看。
- 没有低于阈值的题目时，会显示“没有 AI 自评率过低的题目”。
- 填 `0` 可关闭低自评率提醒；等于阈值时不会提醒。

自评率是模型对自己答案的估计，不代表经过统计验证的正确率。新任务会重新统计本次汇总。

## 六、最终提交

默认关闭自动提交，选完后请检查并手动提交。需要自动提交时：

1. 在设置中勾选 **选完后自动点击提交，并确认页面内的提交对话框**。
2. 保存设置，停止并重新开始现有任务。
3. 从第一题开始作答，确保扩展识别到完整题目。

扩展会尝试点击提交按钮和明确的页面内提交确认按钮。浏览器原生确认框需手动处理。如果页面未显示可识别的成功结果，只会提示检查结果，不把“点击过提交”当作“提交成功”。已经点击并生效的选项或提交操作不会因停止而撤销。

## 七、扫描错题

1. 提交后打开学习通显示批改结果的页面。
2. 点击扩展 → **扫描错题**。
3. 查看识别到的错题、部分正确题，以及页面作答、页面正确答案和识别依据。

错题扫描只读取**扫描时已经加载的题块和可见批改结果**，不调用 AI、不改答案、不自动翻页。不需要设置 API 密钥。

- 已识别到批改结果且没有错题时，会说明本次未发现明确错题。
- 页面尚未批改或无法识别批改结果时，会说明暂时无法判断。
- 部分题目没有结果、批改标记互相冲突时，会单独说明。

低自评率不等于错题。若实际页面的批改标记不在默认适配范围，可在高级设置中配置“错题批改标记”。换页后请重新扫描，弹窗中保留的上次报告会显示扫描时间。

## 八、更新扩展

1. 下载新版源代码，将 `extension` 中的文件覆盖到原来加载的扩展目录。
2. 打开 `edge://extensions`，找到助手并点击 **重新加载 / 刷新**。
3. 刷新学习通答题页面，再打开扩展使用。

不需要卸载扩展。保留原来的加载目录并重新加载时，已有 API 设置会保留。代码改完后只刷新网页、没有重新加载扩展，可能仍然运行旧版后台脚本。

## 九、常见问题

| 问题 | 处理方法 |
| --- | --- |
| 加载时提示找不到清单文件 | 选择含 `manifest.json` 的 `extension` 文件夹，不选 ZIP 或项目外层目录 |
| 扫描不到题目 | 进入实际答题页并刷新；检查是否选对 iframe 区域，必要时配置 CSS 选择器 |
| 不知道 CSS 参数怎么填 | 全部先留空，使用默认识别；识别不全时再按 [参数说明](SETTINGS.md) 调整 |
| API 密钥无效、HTTP 401 | 检查密钥是否属于当前服务商，是否复制完整；不要用网页登录密码替代 |
| HTTP 404 | 检查完整 Chat Completions 地址及模型 ID 是否正确 |
| HTTP 429 | 检查接口额度、限流或服务商提示，稍后重试 |
| 接口超时 | 查看提示的等待秒数，检查网络，或在允许范围内调整超时、更换模型后重新开始 |
| AI 回复不是合法 JSON | 官方接口支持时勾选 JSON 模式，保存后测试；不支持该参数的接口保持关闭 |
| 停止后仍看见旧版提示框 | 确认扩展已重新加载，并刷新答题页面，移除旧版内容脚本 |
| 扫描错题显示无法判断 | 先打开已批改的结果页；若页面已有批改标记，可能需要配置错题标记选择器 |
| 打不开本地模拟页 | 先运行项目里的 `启动本地演示.cmd`，或安装 Node.js 后执行 `node tools/demo-server.mjs` |

完整本地演示方法、隐私及测试说明见 [README](../README.md)。
