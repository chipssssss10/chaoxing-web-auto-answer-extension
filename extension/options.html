AI 接口

可填完整地址，或以 /v1 结尾的服务基地址。保存时只申请该 API 域名的访问权限。

密钥存放在此浏览器的扩展本地存储中，不同步云端；本地存储未加密。网页脚本不接收密钥。题干、选项会发送给上方 API 服务。共享电脑使用后请清除密钥。

自动化行为

例如填 85：低于 85% 时短暂提醒并继续作答，结束后汇总这些题目；没有低于阈值的题目时会明确提示。AI 自评率不是实测正确率，设为 0 可关闭低自评率提醒。

开启自动提交时请从第一题开始。扩展只能核验本次识别到的题目，无法证明整份试卷没有遗漏。图片题、不支持题型或选中状态异常会暂停。浏览器原生确认框需手动处理。

页面适配：自定义 CSS 选择器

默认识别常见题块和单选 / 多选控件。如识别不全，可覆盖下列选择器。题干和选项选择器相对于每个题块查找。请先在模拟页或练习中使用“只答一道”核对。

“扫描错题”只读取当前已加载的题块和批改结果，不调用 AI，不改答案，也不自动翻页。
