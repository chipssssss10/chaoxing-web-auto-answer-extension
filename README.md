# 网页端学习通自动答题扩展

面向 Microsoft Edge / Chrome 的学习通网页答题扩展，当前版本 **0.2.0**。使用自己的 AI 接口，支持文本选择题识别、连续作答、可选自动提交、低自评率提醒与汇总，以及页面批改结果中的错题扫描。

用于电脑 Chrome / Edge 的 Manifest V3 扩展。使用你自己配置的 Chat Completions 兼容 API，读取网页文本题、获取参考答案、选择选项并切换下一题。可单独开启最终自动提交。

**当前验证范围：本地模拟页面和本地模拟 API。尚未在你的学习通账号页面验证，也没有调用真实付费 AI 接口。默认选择器只是常见结构的初始适配，不能保证所有学习通页面直接可用。AI 生成的答案不能保证正确。**

## 0.2.0 更新：低自评率提醒、完成汇总和错题扫描

- 设置中的阈值改为百分比，例如 **85**。低于阈值时，页面右下角短暂提示约 3 秒，然后继续作答，不再因低自评率暂停；填 0 可关闭这类提醒。原有的 0.85 配置会显示为 85%，无需重新填写密钥。
- 每次任务结束，页面提示框和扩展弹窗会汇总低自评率题目的题干、AI 选项和自评率。没有低于阈值的题目时，明确显示“没有 AI 自评率过低的题目”。整页翻题和提交跳转后仍保留本次汇总；新任务会重新统计。
- 新增 **“扫描错题”**。打开有批改结果的页面后点击，可识别当前已加载题块的错误、部分正确标记，或比较页面显示的正确答案与作答选项。报告包含题干、页面作答、页面正确答案（若显示）和判断依据。
- 错题扫描不调用 AI，不修改答案，不提交，也不自动翻页。可以在没有 API 密钥时使用。未批改或无法识别批改标记时会提示无法判断；部分题目没有结果、批改标记冲突时会单独说明，不会直接宣称整份试卷都正确。
- 自评率低只表示需要复核，不等于错题。实际页面的批改标记可能需要适配；高级设置中可以填写“错题批改标记”CSS 选择器。

**更新：** 本地 `extension` 文件夹已更新。保持原加载目录不变，在 `edge://extensions` 中重新加载扩展，再刷新答题页，确认版本为 **0.2.0**。如果从别处加载，请先用新版文件覆盖原目录。无需卸载，API 设置会保留。

## 0.1.1 更新：停止操作和超时提示

- 点击网页右下角“停止”后立即移除提示框，取消本地的请求等待、题间计时和翻页 / 提交确认等待，同时通知后台取消请求。停止前已经选中的答案保持原状。
- 旧请求随后返回或取消时，不会重新弹出提示框，也不会继续选择、翻题或自动确认提交。停止后可以重新开始任务。
- 扩展弹窗里的“停止任务”也会关闭网页提示框。作答完成或暂停后，仍可点击提示框中的“停止”将其收起。
- 接口超时显示“AI 接口请求超时，已暂停”，自动展开说明，展示实际配置的等待秒数和检查网络、调整超时或更换模型后重新开始的建议。接口测试页面也会显示超时原因。超时不自动重试。

更新已有扩展的方法见上方最新版本说明。

## 1. 安装（无需安装 Node.js）

1. Chrome 地址栏打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
2. 打开“开发者模式”，点击“加载已解压的扩展程序”。
3. 选择下载并解压后的本项目内的 **`extension` 文件夹**，选择的文件夹内应直接包含 `manifest.json`。例如项目保存到 `D:\学习通自动答题` 时，选择 `D:\学习通自动答题\extension`。
4. 将“学习通 AI 答题助手”固定到浏览器工具栏。

若使用压缩包，先解压，再选择其中的 `extension` 文件夹；不要直接加载 ZIP 或项目外层文件夹。

## 2. 配置自己的 AI 接口

点击扩展 → “接口与自动化设置”，填写：

| 项目 | 填写内容 |
| --- | --- |
| API 地址 | 服务商的完整 Chat Completions 地址，例如 `https://api.openai.com/v1/chat/completions`；也支持以 `/v1` 结尾的基地址 |
| 模型名称 | 你购买或开通的服务所提供的模型 ID，需支持 Chat Completions |
| API 密钥 | 你自己的 API Key；只在扩展设置中填写，不要发到聊天里 |

点击“保存设置并授权 API 域名”，同意浏览器对该 API 域名的权限请求，再点“测试已保存的接口”。测试会调用一次接口，可能产生服务商费用。只填写服务商主页或 ChatGPT 登录信息不能代替 API 地址和 API 密钥。

默认不发送 `response_format`，通过提示要求 JSON；接口明确支持 JSON 模式时可勾选对应选项。接口返回的选项、题型和置信度仍会经过校验。请求超时最多 25 秒，较慢的模型可能超时暂停。

## 3. 使用

1. 在学习通中打开**实际有题干和选项的答题页面**。初次安装或更新扩展后，先刷新答题页面。
2. 点击扩展 → “扫描当前答题页面”，检查题干、选项和题型是否正确且完整。页面有 iframe 时，会列出识别到的答题区域。
3. 首次使用点击“只答一道”，检查页面实际选择的选项是否与助手显示的参考答案一致。
4. 确认识别正常后，点击“连续作答”。关闭弹窗后仍会继续，可在网页右下角或扩展弹窗点击“停止任务”。
5. 默认选完后停下，请检查并手动提交。需要自动提交时，在设置中勾选“选完后自动点击提交”，保存后重新开始任务。

自动提交应从第一题开始。扩展只核验本次识别到的题目，不能证明未识别到的题目、前面已跳过的题目或服务端保存状态都已完成。请先通过模拟页和练习页核对实际行为。

## 4. 已实现和暂停条件

- 识别文本单选、多选、判断题；判断题也按页面选项顺序映射成 A / B。
- 支持整页多题、同页“下一题”、保持同一路径和作业标识的整页刷新翻题。
- 多选题会取消不应选中的现有选项。点击后核验整组选项状态，未确认成功就暂停。
- AI 请求返回后重新读取题目；题目变化时拒绝使用旧答案。
- 可配置 AI 低自评率提醒阈值（百分比）、每题间隔和每次最多题数。低于阈值只提醒并汇总；AI 自评率**不是实测正确率**。
- 图片、音视频、画布题，填空和简答题，非法 JSON，接口错误，无法核验选中状态或按钮不明确时暂停。
- 不处理验证码和登录；遇到页面验证提示时停止自动化，由你手动处理。
- 自动提交仅识别页面中的提交按钮和明确的提交对话框。原生浏览器确认框需手动确认。没有识别到成功提示时，只报告“请检查结果”，不会把点击按钮当成提交成功。
- 翻页后超过一分钟或作业标识 / 页面路径改变时停止恢复；运行中的页面如果手动刷新，也需要重新开始。完整刷新期间停止任务仍会取消续答。
- 非超星域名的学校门户可能需要进入内嵌的超星实际答题页；未授权的跨域 iframe 无法读取。只在当前页临时注入的其他网站不支持刷新后自动续答。

## 5. 识别不出来时

设置 → “页面适配：自定义 CSS 选择器”。题干和选项选择器相对于每个题块查找，按钮选择器相对于答题区域的文档查找。

| 配置项 | 示例 | 要求 |
| --- | --- | --- |
| 题块容器 | `.TiMu`、`.questionLi`、`.question-item` | 一个元素对应一道题；应包含题干和所有选项 |
| 题干 | `.Zy_TItle`、`.mark_name`、`.question-title` | 只匹配题干 |
| 选项 | `.Zy_ulTop > li`、`.options > li` | 一个元素对应一个选项，包含可点击控件 |
| 下一题 | `#nextQuestion` | 唯一匹配实际的下一题按钮 |
| 最终提交 | `#submitPaper` | 唯一匹配最终提交按钮 |
| 错题批改标记 | `.question-wrong`、`[data-correct='false']` | 匹配错题容器或批改标记；不要匹配题干中的“错误”字样或未选选项 |

优先支持原生 `radio` / `checkbox`。自定义选项需使用 `aria-checked`、`data-selected`、`selected / active / checked / check_answer / check_answer_dx` 等可读状态，否则暂停。不同页面可能需要进一步修改 `dom.js`。修改扩展源文件后，在扩展管理页点“重新加载”，再刷新答题页。

## 6. 不用真实账号和 API 的本地演示

演示服务器需要 Node.js；扩展本身不需要 Node.js。当前电脑可以双击 **`启动本地演示.cmd`**。也可以在项目目录运行：

```powershell
node tools/demo-server.mjs
```

终端保持打开。扩展设置填写：

| 配置 | 值 |
| --- | --- |
| API 地址 | `http://127.0.0.1:8765/v1/chat/completions` |
| 模型名称 | `demo` |
| API 密钥 | `demo-key`（仅供本地演示，不是真实密钥） |

保存并授权后，打开 `http://127.0.0.1:8765/demo`。可以切换“逐题切换”“整页多题”“整页刷新翻题”“不支持题型”来观察行为。多选题故意预先勾选了两个错误选项，用于验证取消错误选项。演示 API 返回固定预设答案，不能用于真实题目。

演示模型改为 `demo-low` 会返回 40% 自评率，可测试短暂提醒和完成汇总；阈值设为 85 时会记录所有演示题。页面中的“错题批改示例”和“全部正确示例”可测试错题扫描，不需要调用接口。错题扫描报告在同一标签页的当前扩展会话中保留，弹窗重新打开后仍可查看；换页后请重新扫描，报告会显示上次扫描时间。

测试完记得把接口、模型和密钥换回真实服务。按 Ctrl+C 关闭本地服务器。

## 7. 隐私和权限

- 密钥只保存在此浏览器的扩展本地存储，不上传到项目代码，不使用云同步。存储没有加密，本机用户或浏览器调试工具仍可访问；共享电脑用完请“清除已保存密钥”。
- 内容脚本的本地存储访问被限制。密钥由扩展后台附到发给所配置 API 的请求上，不放入网页 DOM、题目数据或日志。
- 发送给 API 的是题型、题干和选项；不会主动读取账号密码、Cookie、整页 HTML 或提交账号登录请求。题目文字本身仍可能包含你页面中的信息，使用前请确认接口服务可信。
- 默认匹配超星域名和回环地址 `/demo` 演示页面。API 域名在保存设置时单独申请权限。扫描其他网页使用当前标签页的临时授权。
- 全部脚本随扩展打包，不加载远程脚本，无统计上报。正常答题每题调用一次接口；格式异常不会静默重复调用。
